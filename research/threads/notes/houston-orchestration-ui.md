### Agent tool vocabulary a thread needs

`workspace_info` identity/workspace/request/routing/provider inventory; `pane_spawn` child or independent handoff; `pane_list` children and live spawn budget; `pane_get` record, status/depth/children/brief/staged hold/full result; `pane_read` screen default or historical tail; `pane_prompt` queue/steer/restart; `pane_send_keys` allowlist `esc enter up down tab ctrl+c y n`; `pane_wait` whole inbox or child/kind filter, urgent kinds bypass filter; `pane_kill` own subtree; `pane_submit` result; `pane_pr_watch` / `pane_pr_unwatch`. CLI twins `hs-pane whoami/spawn/list/get/read/prompt/keys/wait/kill/submit/pr-watch/pr-unwatch`. Sources: `docs/internals/orchestration.md:140`, `docs/internals/orchestration.md:1237`, `D/mcp_orchestration.rs:648`.

Prompt modes: `queue` default waits for idle/composer clearance; `steer` immediately writes into working PTY; `restart` interrupts then waits for idle, verified only Codex Escape / Grok Ctrl+C. Refuse question/permission/operator draft/existing queued prompt instead of overwriting. Optional `client_request_id`, 1–64 ASCII alnum/`.`/`_`/`-`, durable same-argument retry receipt, seven days/newest 4096. Wait cap belongs to parent: Claude 90s; Cursor/Antigravity 30s; Codex/OpenCode 600s; Grok effective per-tool budget ≤600s, provisional 30s if unknown. Timeout is not stall. Sources: `docs/user/orchestration.md:205`, `docs/internals/orchestration.md:101`.

Spawnable providers: Claude, Codex, Antigravity, OpenCode, Cursor, Grok. Cursor does not report needs-input. Droid/Copilot/Aider identities only; Custom refused for orchestration spawn. Provider capability text remains visible; missing signal does not prove work. Sources: `D/mcp_tasks.rs:374`, `docs/internals/orchestration.md:143`, `docs/internals/agent-lifecycle.md:70`.

Parent sees composed text through tool/hook/paste; generic header count is `Inbox` with `{n}` / tooltip `{n} unread inbox messages` (`C/SessionPane.tsx:823`). Overview operator-only rows display `summary || body`, without kind icon/colour/body expansion/artifact list, actions `Acknowledge`, `Resolve` (`C/OverviewTab.tsx:65`, `C/OverviewTab.tsx:76`). Child result excerpt shown separately. Colour below is associated session/delegation status, not an InboxKind palette.

### Notification contract (session transitions, not inbox kinds)

`R/orchestrationNotifications.ts:33` skips hidden sessions, **all children (`spawned_by != null`)**, non-running sessions, initial snapshots/revision reset. Top-level working→idle = finished; other→needs-input = needs-input. 2s anti-flap. Unfocused app uses desktop preference `off` / `sound` / `notifications` / `notifications-sound`; focused app can show in-app notice only for offscreen pane, never currently visible pane. Native title `{title} needs your input` / `{title} finished`, body `{agent} · {workspace}`. In-app same title, body `{agent} · {workspace} › {grid}`, warning persistent / success 5,000ms, action `Open pane`. Sounds notify-needs-input.wav / notify-completed.wav. Sources `R/orchestrationNotifications.ts:86`, `R/orchestrationNotice.ts:11`. Inbox needs_input is not itself an in-app toast.

### Colour tokens (avoid equating task, agent and delegation palettes)

`C/ui/StatusLabel.tsx:31`: Working/Ended/Result staged/Pending delivery/Watching = `--info`; Needs input/Waiting for a slot = `--warn`; Done/Ready = `--ok`; Failed = `--stop`; Stalled/Paused = muted; Idle hollow faint. Pills: waiting→`--status-todo-*`, failed→blocked, done→done, working→doing, unknown neutral. `C/ui/PaneControls.tsx:75`: working info pulse, spawning accent pulse, idle muted solid, needs-input warn solid, unavailable outlined. Default theme values (`R/theme.css:289`): info `#7cb7ff`, warn `#f59e0b`, ok `#4ade80`, stop `#ef4444`; light equivalents (`R/theme.css:790`): info `#0891b2`, warn `#ca8a04`, ok `#16a34a`, stop `#dc2626`. Status text variants differ: dark todo `#f0b04f`, blocked `#f09595`, done `#79d79a` (`R/theme.css:304`).

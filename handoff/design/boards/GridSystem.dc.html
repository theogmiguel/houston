Houston · grid system

One thread reads like a conversation. Six read like a control room.

A thread never changes what it can do as the grid fills. It changes how much it shows. Each pane picks its density from the space it actually has, measured on the pane, not from the number of threads or the window size. The same composer, timeline and approval scale through four steps, so a thread moved from solo into a crowded grid is recognisably the same object.

Arrangements as the grid fills

Auto arrange places threads in reading order: the first thread keeps the leading, tallest slot because it is usually the one you started with. Every arrangement is a split tree, so any divider can still be dragged afterwards and the result is kept per grid.

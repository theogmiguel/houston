Quick composer

A system-wide shortcut opens a small panel over whatever is on screen. You pick a project, write the prompt and start a thread without bringing Houston forward. The thread runs on the local server like any other, so the panel closes as soon as the server accepts it. The shortcut is set in Settings → Keyboard, and it can be turned off there.

Behaviour
  • Default shortcut: Ctrl Shift Space on Windows and Linux. Changing or clearing it in Settings → Keyboard takes effect at once.
  • Project and grid default to the last ones used. The model picker shows only providers that are signed in.
  • Ctrl Enter starts the thread. The panel closes when the server accepts it, not before; a refusal keeps the panel open with the text intact.
  • Paste or drop an image to attach it. The draft survives Esc and comes back the next time the panel opens.
  • If Houston's window is closed, the panel still works: it talks to the detached server.
Platform limits
  • Windows and Linux on X11 register the shortcut through the Tauri global-shortcut plugin.
  • Wayland compositors may refuse global shortcuts. Settings then says so by name and offers the tray menu item "New thread…", which opens the same panel.
  • The confirmation toast follows Houston's notification settings; with notifications off, the thread simply appears in the sidebar.

Houston v2

Quiet chrome around loud work.

Houston v2 turns panes into threads: structured conversations with coding agents, arranged in grids, served by a detached server. The interface stays monochrome so the agents' work, and the one thing that needs you, carry all the colour.

The one signature
! StatusGlyph — the only status mark, everywhere
Four grounds

The rail and canvas are close neutrals; cards sit one step up; panes are the deepest ground in graphite and pure white in paper. Every card and pane carries a hairline edge.

Accent, spent twice
Focused field

Blue fills the single affirmative action and draws focus, links and the working arc. Selection and hover stay achromatic.

Three voices
AaAamain

Inter for every control and sentence. Source Serif 4 only for display moments. JetBrains Mono only for machine values.

What this canvas holds

Foundations

Colour roles with measured contrast in graphite and paper, the semantic type scale, the 4pt spacing scale, radius roles and the five-rung material ladder.

Components

Every primitive in its states, the workspace → grid → thread sidebar, the thread timeline and composer, approvals, terminal drawer, diff, preview, palette, dialogs and toasts.

Screens

Full windows at 1440 × 900: a thread in both themes, a grid of three threads with one waiting on you, first run, Settings and the command palette.

Rules every screen keeps

28

Every target is at least 28px tall. Controls, rail rows and pane headers share one height; a 22px icon sits inside a 28px hit area.

4.5

All three text tiers pass 4.5:1 on every ground they sit on, in both themes. Nothing is told by colour alone.

1

One affirmative action per view. Everything else is secondary or ghost; destructive actions carry an icon and never take the primary role.

720

Settings read in a 720px column, centred. Usage uses 960px; Pull requests splits into a 360px list and its detail. The window has no native title bar: minimize, maximize and close sit at the right end of the 40px top bar, as in v1.

Aa

Sentence case everywhere. Tooltips name icon-only buttons; the custom Select replaces the native one.

0

Nothing loops but a real unknown. Only Running pulses; Needs you is static because it waits for you.
